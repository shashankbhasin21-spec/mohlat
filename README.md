# Mohlat (v0)

A free, static, client-side paperwork-deadline helper for Indian families split between India and the UAE, Qatar or the USA.

- Enter an Indian passport expiry plus a UAE residence visa / Qatar QID / US document date, and get a renewal timeline and checklist with official links only.
- All calculation happens in the browser. Nothing is uploaded. Optional saving uses the browser's localStorage only.
- Lead times are shown only where an official source states them (sources listed on the page, last checked 29 Sep 2026).
