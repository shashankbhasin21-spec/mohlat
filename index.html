      2. Check before you pay a recruiting agent

      India’s Ministry of External Affairs (MEA) registers recruiting agents and publishes which ones are active. Before you pay anyone for an overseas job, check them on India’s official eMigrate portal:

      • eMigrate: List of Recruiting Agents (registered, with status)
      • eMigrate: Verify RA Status (needs the agent’s RA ID or ARN)
      • eMigrate: Search Recruiting Agent
      • eMigrate: List of Unregistered Agencies against which Grievances Received (the illegal/unregistered agents list)
      • MEA: Recruiting Agents (RAs) and MEA: Complaints against Recruiting Agents
      • MADAD: MEA’s consular grievance portal

      If the eMigrate page opens on the home screen, use its menu: Recruiting Agents. Mohlat does not check agents for you and cannot confirm any job offer.
